How to copy a table from a website into Excel or Google Sheets

Copying a table from a web page often pastes everything into one column, or drops merged cells. Here are three ways to get a clean table into a spreadsheet, from the simplest to the most reliable.

1. Select and paste

  1. Drag from the first cell of the table to the last cell. Hold Shift and click the last cell if the table is long.
  2. Copy with Ctrl+C (Cmd+C on a Mac).
  3. Click cell A1 in Excel or Google Sheets and paste.

This works for simple tables. It tends to fail when the page uses a grid made of div elements instead of a real table, when rows are loaded as you scroll, or when cells are merged.

2. Paste as plain text first

If the formatting comes out messy, paste into a plain text editor first, then copy from there into the spreadsheet. Tabs between the cells are kept, so the columns usually line up. In Excel you can also use Paste Special, then Text.

3. Use a table copier extension

An extension reads the table's structure instead of the selected text, so the columns stay in place and merged cells are filled in.

  1. Install Table to CSV & Excel – Table Copier from the Chrome Web Store.
  2. Open the page with the table and click the extension icon.
  3. Pick the table from the list. It is outlined on the page so you can see which one it is.
  4. Choose Copy and paste into your spreadsheet, or Download to save a CSV file.

It runs only on the page you click it on, and sends nothing anywhere. See the help page for details.

Save a table as a CSV file

A CSV file is plain text with one row per line and commas between cells. Excel, Google Sheets, Numbers and databases all open it. To make one by hand, paste the table into a spreadsheet and use File, then Save As (Excel) or File, Download, Comma-separated values (Sheets). With the extension, the Download button does this in one step.

Common problems

Everything lands in one column

In Excel, select the column and use Data, then Text to Columns, and pick Tab or Comma. In Sheets, use Data, then Split text to columns.

Numbers turn into dates

Format the destination columns as Text before pasting, or import the CSV through Data, then From Text/CSV and set the column type.

Accented letters look wrong in a CSV

Open the file through the import dialog and choose UTF-8 as the encoding.

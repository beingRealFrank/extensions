How to fill web forms with fake test data

Testing a form by typing "asdf" into every field gets old fast, and it misses bugs that real-looking data would catch, like a long surname, an accented letter or a plus sign in an email. Here are four ways to fill a form with fake data, from quickest to most repeatable.

1. Type a small set of sample values

Keep a note with one full set: a name, an address, a phone number and an email on a domain you control or on example.com. Paste from it each time. This is fine for a handful of runs, and it breaks down when you need variety.

2. Use a data generator

Libraries such as Faker (for JavaScript, Python and other languages) generate names, addresses, dates and text. They are the right choice for automated tests and seed data, because the output can be fixed with a seed and checked into your test suite.

3. Fill the form from the browser

For manual testing, a form-filling extension saves the copy-and-paste step.

  1. Install Fake Form Filler – Test Data Autofill from the Chrome Web Store.
  2. Open the page with the form.
  3. Click the extension icon, or right-click the page and choose "Fill form with fake data".
  4. Check the result and submit.

It fills text, email, phone, address, date and number fields, chooses dropdown options and radio buttons, and ticks required checkboxes. Email addresses use example.com, so a test submission cannot reach a real person. Payment, identity and security-code fields are left empty on purpose. See the help page.

4. Use your browser's own autofill

Chrome can fill a saved address profile into a form. That works for checking layout, but it uses your real details, so avoid it on a shared test site or a screen recording.

What not to put in a test form

  • Real card numbers. Use the test card numbers your payment provider publishes.
  • Real government ID or tax numbers.
  • Other people's names and emails. Use reserved domains such as example.com so that a stray email goes nowhere.

Common problems

A field is rejected as invalid

Check the field's pattern or length rules. Some forms accept only certain phone formats or postcodes for one country.

The page uses a custom dropdown

Custom widgets that are not real select elements may need a click by hand.

The form clears itself after filling

Some frameworks reset a field when it receives no input event. Click into the field once and tab out to trigger validation.

How to export a table from Chrome to Excel

You can get a web table into Excel three ways. Pick by how often you need it and whether the page needs a login.

Paste into a worksheet

Select the table, copy, click A1 in Excel and paste. Use Paste Special, then Text, if formatting comes across badly.

Excel's Get Data from Web

In Excel, choose Data, then Get Data, then From Other Sources, then From Web. Enter the page address and pick the table in the Navigator. It refreshes on demand, but it cannot see pages behind a sign-in, and it misses tables a script draws after the page loads.

Save a CSV and open it

A CSV file opens in Excel with a double click. Table to CSV & Excel – Table Copier works on the page you are looking at, signed in or not: click the icon, pick the table from the list, then choose Copy (paste into Excel) or Download (a CSV file). See the help page.

Fixes

  • Numbers stored as text: use Data, then Text to Columns, then Finish.
  • Long numbers shown as 1E+15: format the column as Text before pasting.
  • Garbled accents in a CSV: use Data, then From Text/CSV and choose UTF-8.
